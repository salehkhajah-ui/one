# Claude Code Skill Pack — 15 skills

Project-level Claude Code skills for this repo, adapted from the "Claude Code Skill Pack — 15 Skills" guide (Notion, by ضياء البوزان). Each skill is a folder with a single `SKILL.md`; Claude Code picks them up automatically — no install step.

From the video: `mcp-builder`, `playwright`, `frontend-design`, `code-review`, `refactor`.
The extra ten: `test-writer`, `git-workflow`, `api-designer`, `database-architect`, `deployment`, `documentation`, `performance-optimizer`, `security-auditor`, `type-safety`, `error-handling`.

The guide's own advice: adopt skills **gradually** — lean on one until it earns its keep, then reach for the next. Having many similar skills active at once can dilute triggering, so feel free to delete the folders you don't use.

The real value is chaining them: design → build → test (`playwright`) → review (`code-review`) → refactor → ship (`deployment`) — a full product loop with you supervising.

Official references: [anthropics/skills](https://github.com/anthropics/skills) (`mcp-builder`, `webapp-testing`, `frontend-design`) and the [Agent Skills docs](https://code.claude.com/docs/en/skills).

Where relevant, each skill carries a short "project note" tying it to this repo's rules (integer-fils money, pure engine, i18n/RTL, Vercel).
