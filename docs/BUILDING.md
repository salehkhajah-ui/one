# PORT — Building & Shipping

Two editions exist:

1. **The Unity game** (this repository) — the full seven-phase build for
   iOS / Android / desktop.
2. **The web edition** (`web/`) — a playable browser slice deployed as an
   installable PWA at https://port-harbor-game.vercel.app (play in any
   browser; installable on desktop Chrome/Edge, Android Chrome, and iOS
   Safari via Share → Add to Home Screen).

## Unity: run in the editor

See `README.md` — open the folder in Unity 2022.3 LTS+, open any scene,
press Play. Everything is constructed at runtime by `GameBootstrap`.

## Unity: mobile builds

### Android (.apk / .aab)

1. Install the **Android Build Support** module via Unity Hub (includes
   SDK/NDK/OpenJDK).
2. `File → Build Settings → Android → Switch Platform`.
3. `Player Settings`:
   - Company/Product name, package id (e.g. `com.saleh.port`).
   - Default orientation: **Landscape**.
   - Minimum API level 24+; target the latest.
   - Scripting backend **IL2CPP**, target architectures ARM64 (+ARMv7 if
     you want 32-bit).
4. **Build** for a sideloadable `.apk`, or **Build App Bundle (.aab)** for
   the Play Store (requires a keystore — Unity can generate one; keep it
   safe, uploads must always be signed with it).
5. Play Store: create the app in the Play Console ($25 one-time), upload
   the `.aab`, fill the listing, submit for review.

### iOS (.ipa)

1. Requires a Mac with Xcode and an Apple Developer account ($99/yr).
2. Install the **iOS Build Support** module; `Switch Platform → iOS`.
3. Player Settings: bundle id, landscape orientation, target iOS 13+.
4. **Build** produces an Xcode project; open it, set your signing team,
   then archive (`Product → Archive`) and distribute via App Store
   Connect / TestFlight.

### Desktop (Mac / Windows / Linux)

`Build Settings → Windows/Mac/Linux → Build` produces a double-clickable
standalone app. No developer account needed to share directly (macOS
Gatekeeper will warn unless you notarize).

## In-app purchases (real money)

The web edition's Harbor Shop items (flagship ship, Mega Port, gold
livery) are the intended IAP catalog. In the Unity build, wire them
through **Unity IAP** (`com.unity.purchasing`) so Apple/Google process
payment; never charge cards directly in-app on the stores. On your own
website, Stripe Checkout is the equivalent.

## Web edition (`web/`)

Static files — `index.html` (the whole game), `manifest.webmanifest`,
`sw.js` (offline cache), and icons generated by `geniconpy.py`. Deploy by
copying the folder to any static host (Vercel/Netlify/GitHub Pages).
`sw.js` bumps its cache name (`port-vN`) on each release to invalidate
old caches. A fully offline single-file build is made by inlining
three.min.js in place of the CDN `<script>` tag.
